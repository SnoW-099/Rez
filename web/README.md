# Panel Web de Rez Bot

Este directorio contiene los archivos para el panel web del bot de Discord Rez.

## Estructura de Directorios

- `index.html`: Página principal del panel web
- `css/style.css`: Archivo de estilos
- `js/script.js`: Archivo de scripts para interactividad
- `img/`: Carpeta para imágenes

## Características

- Visualización del estado del bot
- Acceso a funciones como balance, ranking, etc.
- Interfaz responsive para dispositivos móviles
- Diseño moderno y amigable
