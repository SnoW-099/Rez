### 🌑 THE PHILOSOPHY
**Rez Frontend** is a visual extension of the bot's core. Built on the **Liquid Black** design system, it prioritizes absolute darkness, speed, and intuitive data visualization.

</div>

### 🚀 Core Architecture
* **Sonar Loader:** Custom CSS wave-pulse animation for the boot sequence.
* **Bento Layout:** Modular grid for real-time stats (Servers, Users, Command history).
* **Reactive UI:** Minimalist buttons and cards with magnetic hover effects.
* **Darkness First:** Pure `#000000` canvas to focus on high-fidelity data.

| Component | Technology |
