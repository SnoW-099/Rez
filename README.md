### 🌑 OVERVIEW
**Rez** is a dual-purpose Discord ecosystem. It combines a robust **Security Engine** with a competitive **Economy Framework**, all monitored through a high-fidelity **Liquid Black** terminal interface.

</div>

### 🛡️ Core Infrastructure
* **Security Module:** Warning systems, invite anti-spam, and automated moderation logs.
* **Economy Engine:** Multi-currency support, global rankings, and persistent data storage.
* **Liquid Dashboard:** A real-time Bento-style web interface for system monitoring.
* **Bridge API:** Custom Flask-based communication between the Bot core and the Frontend.

### 🛠️ Technical Stack
| Layer | Technologies |
| :--- | :--- |
| **Bot Core** | Python, Discord.py / Disnake |
| **Database** | Supabase (PostgreSQL) / MongoDB |
| **API Bridge** | Flask + Flask-CORS |
| **Interface** | Vanilla JS, CSS3 (Liquid Black Framework) |

### 🚀 Quick Start
1. **Invite the bot** using the official dashboard.
2. **Access the Web UI** to monitor server stats in real-time.
3. **Configure modules** using the `!setup` command within Discord.
